# Deus Intus Web Experience Department

This department is the sanctioned quality lane for public-facing websites, funnels, product UI, web apps, prototypes and interactive experiences.

## Purpose

A build is not complete because it compiles. Public-facing work must pass independent creative, UX, rendered-visual, accessibility, performance and engineering gates.

## Preferred capability stack

Use owned/open/local capability before paid or credit-metered services:

1. Canonical Deus Intus design-system and product sources.
2. Build Web Apps / frontend-app-builder.
3. Open Design.
4. Open CoDesign.
5. Huashu Design.
6. Creative Production / included image generation where available without extra spend.
7. Webstudio.
8. ComfyUI and other local creative tooling.
9. Open-source frontend and QA tools.

Penpot may be used as an optional open/self-hosted canvas. Figma is not a required stage.

Replit, Lovable, Webflow, Canva AI, Adobe and other paid/freemium builders are not default dependencies. They require explicit user choice or a demonstrated unique need.

## Standard route

```
brand/product truth
      ↓
existing-product audit
      ↓
3 differentiated visual directions when direction is unresolved
      ↓
independent creative review
      ↓
approved full-surface target
      ↓
frontend implementation
      ↓
rendered desktop + mobile comparison
      ↓
UX / interaction verification
      ↓
accessibility + performance
      ↓
engineering verification
      ↓
independent release decision
```

The implementation agent cannot be the final release reviewer.

## Anti-slop veto

Reject output that relies on generic AI conventions instead of deliberate design, including unjustified giant decorative SVGs, reflexive sacred geometry, glowing gradients/blobs, repetitive card grids, fake eyebrow pills, invented metrics, stock-looking imagery, desktop merely collapsed into mobile, dead controls, or generic component-library aesthetics.

SVG is appropriate for logos, icons, diagrams, mathematically justified geometry, data graphics and deliberate illustration/motion. It is not a substitute for art direction.

## Release status

Use only:

- VERIFIED COMPLETE
- PARTIALLY VERIFIED
- BLOCKED — HUMAN ACTION REQUIRED
- FAILED VERIFICATION
